# 📦 Modèles

Les fabricants et leurs modèles associés sont générés automatiquement depuis les CVE.

Si vous avez un modèle ou un fabricant qui n'existe pas dans les CVE et que vous voulez le créer, vous pouvez venir sur la page dédiée.

A savoir, un modèle est lié à un fabricant, il faudra donc créer le fabricant et ENSUITE le modèle.
