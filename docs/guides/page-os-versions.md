# 🖥️ OS & Versions

Cette page a plutôt pour but d'être consultée, sans ajouter de nouvelle entrée.

Les OS et leurs versions associées sont générés automatiquement depuis les CVE.

Si vous avez un OS ou une version qui n'existe pas dans les CVE et que vous voulez le ou la créer, vous pouvez venir sur la page dédiée.

**A savoir, il est préférable de ne rien toucher ici et de plutôt ajuster au niveau des paramètres de corrélation !**

En effet, si vous rajoutez des OS et versions qui ne sont donc pas liés à des CVE, la corrélation des assets qui ont ces OS/Versions ne pourra pas se faire car non liés.
