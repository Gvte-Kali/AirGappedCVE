A FAIRE : 

Lors de la création d'un type d'équipement dans la page paramètres, le 'code' doit être exactement une des valeurs ENUM de la table assets --> 'type_equipement'. 
Ce fonctionnement pose un problème car si on veut créer un nouveau type d'équipement, on est obligé de choisir 'autre'.
La solution temporaire et peu propre serait de mettre un menu déroulant pour le code bloquant la possibilité de mettre ce que l'on veut dans le champ.
