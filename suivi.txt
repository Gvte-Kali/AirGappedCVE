Architecture :
  GET  /api/import/template         → XLSX vierge + listes déroulantes
  GET  /api/import/template-exemple → XLSX avec 5 lignes d'exemple
  POST /api/import/preview          → validation sans insertion
  POST /api/import/confirm          → insertion avec choix update/skip

         Ajouter : openpyxl

[✅] F2 — routers/import_assets.py
         • Chargement des référentiels depuis BDD :
           - product_vendors (nom, id)
           - product_models (nom, vendor_id, id)
           - os_versions (os_nom distinct, version, id, type_produit)
           - equipment_types (label, id)
         • GET /api/import/template → génère XLSX vierge
           Colonnes :
             client_nom, site_nom, nom_interne*, type_equipement*,
             fabricant*, modele, os_nom, os_version, version_os_libre,
             firmware, adresse_ip, adresse_mac, hostname, numero_serie,
             niveau_criticite*, statut_operationnel, date_installation,
             date_fin_garantie, notes
           Listes déroulantes (feuilles masquées _Ref*) :
             - type_equipement ← equipment_types.label
             - fabricant ← product_vendors.nom
             - modele ← product_models.nom
             - os_nom ← os_versions.os_nom distincts (type=os)
             - os_version ← os_versions.version (type=os)
             - firmware ← os_versions.label (type=firmware)
             - niveau_criticite ← faible/moyen/eleve/critique
             - statut_operationnel ← actif/inactif/maintenance/hors_service
         • GET /api/import/template-exemple → même chose + 5 lignes exemple
         • POST /api/import/preview → validation + rapport :
           - Lignes valides / avertissements / erreurs bloquantes
           - Nouveaux clients détectés
           - Nouveaux sites détectés
           - Doublons (nom_interne + site) détectés
           - Erreurs bloquantes : fabricant absent, nom_interne vide
           - Avertissements : version_os_libre (corrélation informatif)
         • POST /api/import/confirm → insertion dans l'ordre :
           1. Clients (créer si absent)
           2. Sites (créer si absent, lié au client)
           3. Assets (insert ou update/skip selon choix utilisateur)
           Paramètre : on_duplicate = "update" | "skip"
