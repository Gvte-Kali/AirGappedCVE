[ ] I003 — Réfaction logique Raspberry Pi : 
         Pour les Raspberry pi, on utilise DietPi. Actuellement la corrélation indique qu'il n'y a pas d'os normalisé donc on skip les raspberry.
         Cependant, on a uniquement Debian dans les OS disponibles dans la liste de ce qui pourrait être pertinent.
         DietPi n'existe pas dans les OS. 
         L'usage de DietPi fait qu'il y a très peu de composants, donc très peu de vunérabilités debian sont réellement concernées pour mon cas d'usage.
         Je souhaite que les vulnérabilités trouvées dans le kernel linux soient remontées, sans que les cve liées à debian ne le soient. 
         Sachant que dans mon fichier /scritps/config.yml, j'ai ceci en os_vendor_map : DietPi: linux
         Qu'est-ce que la corrélation va prioriser ? Mon fichier de config ou ma configuration dans equipment-type ?
         Et qu'est-ce qui est le plus pertinent pour ma configuration ?
