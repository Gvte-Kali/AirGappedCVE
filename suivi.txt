[ ] G1 — Créer scripts/asset-manager (script bash exécutable)
         chmod +x scripts/asset-manager
         Charge les variables depuis .env automatiquement
         Usage : ./scripts/asset-manager <commande>
         (ou via alias : asset-manager <commande>)

         ── FastAPI ──────────────────────────────────────────
           start       → démarre le service systemd FastAPI
           stop        → arrête le service
           restart     → redémarre le service
           status      → statut systemd + PID + port

         ── Logs ─────────────────────────────────────────────
           logs        → tail -f FastAPI.log (50 dernières lignes)
           logs-err    → tail -f filtré ERROR/EXCEPTION uniquement
           logs-corr   → tail -f filtré lignes de corrélation

         ── BDD ───────────────────────────────────────────────
           db          → echo la commande mysql complète
           db-connect  → connexion directe à mariadb
           db-backup   → dump complet → /tmp/am_backup_YYYYMMDD.sql
           db-schema   → dump structure → schema.sql
           db-size     → taille de chaque table en Mo
           db-vacuum   → OPTIMIZE TABLE sur corrélations + cve
           db-check    → CHECK TABLE corruption

         ── Corrélations ─────────────────────────────────────
           correlate         → lance le pipeline complet
                               (correlate + analyze + run-all)
           corr-clear        → supprime toutes les corrélations
                               (avec confirmation Y/N)
           corr-clear-asset  → supprime corrélations d'un asset
                               (demande l'id interactivement)
           corr-stats        → COUNT par statut depuis la BDD
           corr-rejects      → 20 derniers rejets de corrélation
           corr-clear-rejects→ vide la table correlation_rejects
           corr-top          → top 10 assets par nb corrélations

         ── Documents ────────────────────────────────────────
           docs-list   → liste les PDFs avec taille et date
           docs-clear  → supprime tous les PDFs (avec confirmation)
           docs-size   → taille totale du dossier documents

         ── CVE ──────────────────────────────────────────────
           cve-stats   → COUNT CVE par vendor dans la BDD
           cve-last    → 10 dernières CVE importées

         ── Audit ────────────────────────────────────────────
           audit-assets  → assets sans vendor NVD (jamais corrélés)
           audit-os      → assets sans OS normalisé
           audit-orphans → corrélations sans asset ou CVE valide

         ── Système ──────────────────────────────────────────
           sys-info      → RAM, CPU, température, uptime
           sys-ports     → vérifie ports 3000/8000
           sys-services  → statut FastAPI + MariaDB + Grafana
           check-env     → vérifie variables .env présentes
           check-db      → connexion BDD + COUNT tables principales
           check-disk    → espace disque documents + logs
           update-deps   → pip install -r requirements.txt
           version       → Python + FastAPI + MariaDB versions
