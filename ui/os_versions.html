🖥️ OS & Versions — Guide

Ce référentiel contient les OS, firmwares et BIOS normalisés selon la nomenclature NVD. Un asset associé à une entrée de ce référentiel bénéficie d'une corrélation CVE précise.

Champs NVD

  • nvd_vendor — Vendor NVD exact en minuscules. Ex: microsoft, synology.
  • nvd_product — Produit NVD exact. Ex: windows_server_2022, diskstation_manager.
  • Version — Version affichée dans l'interface. Ex: 2022, 7.1.1.
  • Type produit — os, firmware ou bios.

Si la version exacte de votre équipement n'est pas listée, utilisez le champ texte libre dans la page Assets — la corrélation sera en mode informatif.
